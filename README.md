# 🛒 App de Lista de Compras

Aplicação multiplataforma desenvolvida com **C# e .NET MAUI** para gerenciamento de listas de compras.

## 🎯 Objetivo

O projeto foi desenvolvido para praticar a criação de aplicações multiplataforma utilizando .NET MAUI, trabalhando interface, organização de código e interação com dados.

## 🛠️ Tecnologias

- C#
- .NET MAUI
- .NET

## ✨ Funcionalidades

- Criação e gerenciamento de itens de compra
- Organização da lista
- Interface multiplataforma

## 🚀 Como executar

1. Clone o repositório.
2. Abra `AppMauiListaCompras.sln` no Visual Studio.
3. Restaure as dependências.
4. Selecione a plataforma desejada.
5. Execute a aplicação.

## 📚 Aprendizados

Projeto desenvolvido como parte da minha evolução prática em C# e .NET MAUI, com foco na construção de aplicações multiplataforma e interfaces de usuário.
